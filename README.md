# ihcux-foca-ai-app

## 🎯Objetivo
O desafio é aplicar conceitos de Calm Technology (Tecnologia Calma),
criando uma interface que seja informativa, mas que não gere ansiedade ou
vício.

## 🖼️Cenário do Problema
Uma startup de psicologia quer lançar o "FocaAí", um aplicativo que ajuda
estudantes e profissionais a gerenciarem seu tempo de foco e reduzirem o
uso excessivo de redes sociais durante o trabalho/estudo.
